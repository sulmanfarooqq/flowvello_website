# Flow Vello — Claude Code Instructions

Read `AGENTS.md` before changing the project.

## Mission
Maintain a premium, credible, SEO-first agency website without drifting from Flow Vello's established visual identity.

## Rules
1. Reuse existing HTML/CSS/JS patterns before adding new ones.
2. Keep pages static-first and lightweight.
3. Use Teko for display headings and Rubik for body/interface text.
4. Use `#fb383b` as the primary accent and `#222429` as the dark surface.
5. Preserve existing navigation/footer structure and shared behavior.
6. Do not fabricate proof, clients, metrics, reviews, awards, or contact information.
7. Use semantic HTML and accessible interactions.
8. Every indexable page needs complete SEO metadata and truthful JSON-LD.
9. Respect `prefers-reduced-motion`.
10. Keep secrets out of the repository.

## Before editing
Inspect the relevant page, shared CSS, shared JS, and the applicable document in `docs/`.

## Before declaring done
Check desktop/mobile layout, navigation, links, assets, SEO metadata, structured data, accessibility basics, and browser console errors.
